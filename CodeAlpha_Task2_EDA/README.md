# Exploratory Data Analysis (EDA) – CodeAlpha Task 2

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a Superstore sales dataset using Python. The objective is to understand the structure and quality of the data, identify business trends, investigate relationships between variables, and communicate findings through statistical analysis and visualizations.

## Objectives
- Explore dataset structure, columns, and data types.
- Identify missing values and duplicate records.
- Generate descriptive statistics.
- Investigate potential outliers.
- Analyze sales and profit by category and region.
- Examine monthly sales trends.
- Study relationships between discounts, sales, and profit.
- Perform statistical hypothesis tests.
- Create static and interactive visualizations.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Plotly
- VS Code

## Visualizations
The project generates visualizations such as:
- Correlation heatmap
- Sales and profit distributions
- Box plots for potential outliers
- Category sales and profit comparison
- Monthly sales trend
- Discount versus profit scatter plot
- Interactive sales versus profit chart (HTML)

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Install the dependencies:

   `python -m pip install -r requirements.txt`

4. Place the source dataset at the location expected by the Python script.
5. Run the analysis:

   `python eda_analysis.py`

6. Open the generated charts and reports in the `outputs/` folder. Open the interactive HTML chart in a web browser.

## Key Findings
The analysis identified Technology as the leading category for total sales and reported profit, and the West region as the leading region for total sales. Refer to the generated reports for detailed results.
