# CodeAlpha Task 2 – Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a Superstore sales dataset using Python. It explores data quality, statistical patterns, sales and profit trends, potential outliers, and relationships between business variables.

## Objectives
- Understand the dataset structure and data types.
- Identify missing values and duplicate records.
- Generate descriptive statistics.
- Detect potential outliers using statistical methods.
- Analyze sales and profit across categories and regions.
- Examine monthly sales trends.
- Investigate the relationship between discounts and profit.
- Perform statistical hypothesis testing.
- Present insights through data visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Plotly
- VS Code

## Visualizations
The project includes:
- Correlation heatmap
- Sales and profit distribution plots
- Box plots for outlier analysis
- Category-wise sales and profit comparison
- Monthly sales trend
- Discount vs. profit scatter plot
- Interactive sales vs. profit visualization (HTML)
